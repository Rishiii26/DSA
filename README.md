# DSA Practice

A collection of my **Data Structures and Algorithms (DSA)** practice problems and solutions, primarily implemented in **Java**.

This repository contains the problems I solve while learning and improving my problem-solving skills, with a focus on understanding concepts, writing clean code, and analyzing time and space complexity.

* Searching
* Binary Search

* Linked Lists
* Stack & Queue

* Heaps
* Graphs
* Dynamic Programming
* And more...
